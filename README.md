A [make.fun](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214) bounty entry: the funniest one-line excuse a robot vacuum gives for missing a spot, in 140 characters or fewer.

## The excuse

> My cliff sensor mistook the dark rug for a staircase, so I filed that spot under 'certain death' and went back to my dock.

## How it works

`main.py` (stdlib only) writes that single line to `entry.txt` inside
`MAKEFUN_OUTPUT_DIR` (default `/output`).

```sh
python3 main.py
```

The program self-checks the 1–140 character gate before writing.
